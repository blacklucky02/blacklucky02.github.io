每一篇筆記裡有什麼？

每篇採中英對照，以雙欄呈現 Key Points 與 Senior Notes Supplement，不是只有標題清單
幾乎每篇都有「常見錯誤選項解析」，以及 3 題練習與詳解，用來熟悉常見陷阱

  • 中英對照雙欄：Key Points（筆記中標示為 Saunders Key Points）與 Senior Notes Supplement
  • 幾乎每篇附常見錯誤選項解析，以及 3 題考題測驗與詳解
  • 部分篇目將高頻易混概念寫在同一份筆記，例如 DKA 與 HHNS、高／低血鉀、MI 與 Angina、PAD 與 DVT，以症狀、危險因子、併發症與處置逐項對照

筆記中的 Key Points 欄位標示為 Saunders Key Points，僅描述編排方式；本教材為獨立整理，與 Saunders／Elsevier 或 NCSBN 無官方關係或背書

Why these notes

這套內容的六個重點

以下皆根據實際筆記、圖卡與附錄整理，不誇大通過率，也不聲稱涵蓋所有考題

01 / NOTES

七大單元、101 篇完整筆記，中英對照

每篇是 Key Points 與 Senior Notes Supplement 雙欄編排，把重點與補充寫在一起，方便對照複習

02 / PRACTICE

常見錯誤選項解析，與 3 題練習及詳解

幾乎每篇都有陷阱解析與三題測驗及詳解，直接練習常見的命題干擾項

03 / CARDS

101 張講義圖卡，與筆記一對一

一頁圖像化重點、步驟與 Quick Review，方便快速翻閱與考前複習

04 / MEDS

另附藥物與檢驗工具

含高頻藥物總表、抗生素總表、GERD 用藥表、胰島素作用時間圖，合計 80+ 種藥物；並附檢驗魚骨圖與 emia 單字速記卡

05 / CORE

101 個核心考點速讀

另附《101 篇核心重點速讀》（中文、英文、中英對照三份），每篇濃縮一個核心判斷考點，適合作考前速讀
這 101 個核心考點與正文中的 6,000+ 則知識點是不同層次的整理

06 / COMPARE

對照題寫得細

多篇把高頻易混概念寫在同一份筆記裡，例如 DKA 與 HHNS、高／低血鉀、MI 與 Angina、PAD 與 DVT，正文用症狀、危險因子、併發症、處置逐項對照

Coaching

陪跑方案包含什麼？

適合希望在刷題與複習過程中，有人一起檢視進度、弱點與藥物重點的考生
陪跑服務自開通起，至學員參加 NCLEX-RN 考試之日結束，請於確定應考日後盡速告知我們，以便在考前安排四次 meeting

  1. 四次 meeting

    與你約定時間，進行四次會議（線上進行方式於購買時確認），討論進度、問題與接下來的準備方向

  2. 刷題指引

    協助你規劃與進行刷題，讓練習更有節奏，而不是盲目累積題數

  3. 刷題弱點分析

    一起檢視答題弱點，對準需要補強的地方，讓複習更集中

  4. 藥物教學

    搭配藥物整理，說明備考時需掌握的藥物重點
